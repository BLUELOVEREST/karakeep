# 用户独立 AI 配置

标签、图片标签和总结使用收藏所属用户的 AI 配置；手动总结使用操作用户自己的配置。没有服务器默认供应商，也不会借用其他用户的密钥。首次升级后，原来的服务器 AI 环境变量不会自动导入个人配置。

## 管理员准备

使用 `openssl rand -base64 32` 生成独立主密钥，写入部署目录的私有 `.env`：

```dotenv
AI_CONFIG_ENCRYPTION_KEY=<独立的 32 字节 Base64 主密钥>
# 仅访问内网 Ollama 等服务时需要，填写完整 origin，多个以逗号分隔：
AI_ALLOWED_PRIVATE_ORIGINS=http://192.168.1.10:11434
```

Web 和 workers 必须使用同一主密钥。主密钥不保存到数据库，须与数据库分别备份；丢失或直接更换后无法解密旧 Key，需要用户重新填写。不配置有效主密钥时，界面能查看状态，但不能保存新连接或调用个人 AI。不要使用 `NEXTAUTH_SECRET` 或公开值代替。

确认 Compose 的 `environment` 显式传入上述变量，或使用 `env_file` 将私有配置注入容器；仅在 `.env` 中填写但没有引用，不会自动传入容器。修改后重新创建容器，例如 `docker compose up -d --no-deps karakeep`。单纯 `restart` 不会重读 `.env`。数据库迁移新增独立配置表，不重建收藏数据。

默认阻止内网、回环等地址；只对管理员明确允许的 origin 放行。云元数据、链路本地地址和 HTTP 重定向始终禁止。容器内 `localhost` 指向容器自身。仅为可信用户和可信服务添加白名单。

## 用户配置

打开 Web「设置 → AI」，选择 OpenAI 兼容接口或 Ollama，填写 URL 和 Key。OpenAI 兼容地址通常包含 `/v1`；Ollama 使用服务根地址。Ollama 可不填 Key。

获取模型后分别选择文本模型和可选图片模型。模型按明确的 `厂商/模型` 前缀分组，并自然排序；无前缀的不猜测厂商。列表失败时可手动输入准确的模型 ID，刷新不会删除已有选择。

测试文本连通性，再按需测试视觉能力。测试会调用所选服务，可能产生少量费用；使用通用提示词和临时生成的测试图片，不读取个人收藏。模型出现在列表中不代表能调用，也不代表支持视觉；超时或结果无法验证不等于不支持。

默认选择结构化输出，服务商不支持时再改为 JSON 或普通文本。启用个人 AI 后保存立即生效，容器重启后仍保留。输入框留空会保留现有 Key；切换供应商或 URL 必须重新输入 Key。清除 Key 同时关闭个人 AI。

自动标签默认开启，自动总结默认关闭；均需先启用个人 AI。旧收藏不会自动全部重跑，可先用单条收藏验证，避免批量产生费用。图片标签需要配置可用的视觉模型，纯视频不会自动获得视频理解能力。

## 数据与分类

推理语言可从下拉菜单选择，也可选择“跟随界面语言”或自定义。跟随模式使用该用户在 User Info 中最后保存的界面语言，后台自动标签、总结和手动总结使用相同规则。不同设备修改界面语言时，以最后一次保存为准；不自动重做已有标签或总结。未设置推理语言时默认简体中文，旧的自定义语言原样保留。

Curated Tags 是限定 AI 标签候选范围：选定已有标签后，提示词要求只从这些标签中选择；未选择时允许生成新标签。这是模型提示词约束，不是文件夹分类，也不是模型输出必然合规的保证。

云端推理会向所选服务发送相应的标题、正文或图片，应确认隐私和费用。Key 加密保存，API 仅返回是否已配置，不返回明文或密文。

AI 生成标签和总结，不直接选择 List。可使用规则引擎，例如添加“NAS”标签时移入“数码/NAS”。Embedding、语义搜索和索引的服务器配置保持独立，本次不迁移其模型或向量索引。
