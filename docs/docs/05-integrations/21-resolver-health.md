# Resolver 服务连接面板

管理员的服务器统计页面会分别显示基础服务和五个平台 resolver 的连接状态。只有拥有系统管理读取权限的管理员可以调用 `admin.checkResolverConnections`。

| 平台 | 健康接口 |
| --- | --- |
| 小红书 Spider_XHS | `GET /health` |
| 酷安 | `GET /health` |
| 什么值得买 | `GET /health` |
| 抖音 | `GET /api/v1/health` |
| 微信公众号 | `GET /api/karakeep/v1/health` |

健康地址从当前服务端配置的 resolver 地址派生，不接受客户端传入 URL。探测不提交文章、下载任务或配置修改，不发送 Cookie、服务认证码或 URL 查询参数；不跟随重定向。HTTP 成功响应且 JSON 中 `status` 为 `ok` 才显示已连接。响应内容和底层异常不会直接返回浏览器。

- 未配置：没有启用对应 resolver 地址。
- 已连接：健康接口响应正常，同时显示检查时间和耗时。
- 检查失败：超时、网络失败、HTTP 错误或响应格式异常。
- 未检查：健康接口返回 404/405，或选择了没有适配健康接口的 XHS MCP 后端。这不代表服务离线。

每项检查最多等待三秒，五项并行；结果缓存十秒，并合并同一进程内的并发检查。刷新不会占用抓取队列，resolver 异常也不会阻塞原有基础服务连接面板。

服务连通性不代表 Cookie 有效，也不保证特定文章能成功解析。Cookie/认证失败仍以实际抓取事件和 Resolver Settings 为准。

升级 Karakeep 服务端后可看到新面板，不需要更新 APK。微信需同时升级包含新健康接口的 resolver 镜像；旧版显示未检查，其已有文章接口不受影响。小红书、抖音、酷安、什么值得买复用现有健康接口，不需要为本功能修改代码。后台任务统计保持原样。
